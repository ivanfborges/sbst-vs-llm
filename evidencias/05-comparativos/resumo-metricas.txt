3) COMPARAÇÃO DIRETA
- Branch coverage: igual (94% para ambos)
- Instruções: EvoSuite ligeiramente maior (98% vs 97%)
- Mutation Coverage: LLM superior (88% vs 64%)
- Test Strength: LLM superior (88% vs 67%)
- Mutações sem cobertura: LLM melhor (0 vs 1)
- Execuções no PIT: LLM menor (83 vs 128)

4) GANHOS DO LLM EM RELAÇÃO AO EVOSUITE
- +24 pontos percentuais em Mutation Coverage
- +21 pontos percentuais em Test Strength
- +6 mutantes mortos
- -45 execuções no PIT
- Redução aproximada de 35,2% nas execuções do PIT

5) OBSERVAÇÃO SOBRE OS 3 MUTANTES SOBREVIVENTES NO LLM
- Tipo: ConditionalsBoundaryMutator
- Linha: 17
- Condição associada: a <= 0 || b <= 0 || c <= 0
- Interpretação: fortes indícios de mutantes equivalentes ou quase equivalentes,
  pois a lógica posterior ainda tende a classificar os casos como INVALID.

6) SÍNTESE FINAL
- EvoSuite: boa cobertura estrutural e geração automática rápida
- LLM: melhor efetividade prática, melhor mutation coverage e testes mais legíveis
- Conclusão: a estratégia LLM + PIT (refinamento iterativo) foi a mais eficaz no estudo de caso
